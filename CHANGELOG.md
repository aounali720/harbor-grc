# Changelog

## 1.1.2 — 2026-10-27

Account setup can generate a random passphrase locally with --generate-password.
Interactive entry now validates length before confirmation and retries with a
character-count message. Account creation/reset clears only the user's failure
window while retaining shared IP protection; reset still revokes sessions.

## 1.1.1 — 2026-10-27

Verified the 12-entry official-source publication catalog, added SP 800-61 Rev. 3 and a Respond-function starter reference, expanded ISO/CSF working guidance, and improved framework search, source links and test coverage. Mappings remain partial and project-authored.

## 1.1.0 — 2026-10-27

Added a sourced NIST/ISO reference library, selected partial control mappings, authenticated reference endpoints, local mapping/evidence counts, framework snapshots in exports, and CSF/ISO assessment templates. New demos include the starter mappings; existing tagged demos can add them through an audited operator command.

## 1.0.0 — 2026-10-26

Initial portfolio release: SaaS, cloud, and vendor registers; evidence reviews;
risk decisions; offline ASFF import; audit checkpoints; authenticated console;
operator CLI; handbook; and reusable templates.
